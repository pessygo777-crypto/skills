# Domain Docs

## Layout

This repository uses a single context:
- GLOSSARY.md at the repository root.
- Architecture decisions in the existing .agents/adr/ directory.

## Before exploring

Read GLOSSARY.md and architecture decisions relevant to the task.
Also read relevant decisions under docs/adr/ if that directory exists.

If documentation is absent, proceed silently.
Domain-modeling creates documentation when terms or decisions
are actually resolved.

## Vocabulary and decisions

Use the glossary's terms consistently.
Surface conflicts with existing architecture decisions explicitly.
